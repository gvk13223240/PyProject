# PyProject
This repository contains a collection of Python-based projects focused on data science, machine learning, and image processing.
## Project Structure
- **ImageCompression** – Image compression using Singular Value Decomposition (SVD).
- **edgedetector** – Edge detection techniques using OpenCV (Sobel, Canny).
- **imagefilter** – Image filtering operations and transformations.
- **ImageDifferenceChecking** – Pixel-wise image comparison to detect differences.
- **churn-prediction** – Machine learning model and Streamlit app for customer churn prediction.
- **pptx-generator** – Python utility to convert screenshots/images into PowerPoint slides.
Each project is implemented as a standalone module with its own logic and dependencies.
